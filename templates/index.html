Dead Feature Detector

Find C++ code that's safe to delete — automatically

Large C++ projects accumulate #ifdef guards Lines like #ifdef MY_FEATURE … #endif that wrap code so it's only compiled when a certain flag is turned on. Over time, some of these flags get forgotten. for features that are never enabled in practice. This tool scans your build system, maps every conditional block, and traces the call graph to find code that can never run in any real build.

🚀 Analyze a Project

Point this tool at any C++ project that uses CMake. It will automatically read the build settings, scan the source code, and generate a report.

Step 1 — Read the Build System

CMake tells us which feature flags (#define values) are switched on or off in each build target. Think of this as reading the project's "settings sheet".

Step 2 — Map the Guards

We scan every C++ source file using a Clang plugin and record precisely which lines are wrapped in #ifdef / #ifndef blocks, and what flag controls each block.

Step 3 — Trace Execution Paths

We compile the project to LLVM intermediate representation (IR) and walk the entire call graph from main(), finding every line that can ever actually run.

Step 4 — Find Dead Code

Cross-referencing the three data sets: if a guarded block is never reachable in ANY build configuration, it's dead. We score each finding HIGH or MEDIUM confidence.
